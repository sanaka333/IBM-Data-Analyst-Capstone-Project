# IBM Data Analyst Capstone Project
Analyzed technology survey data using Python and Pandas and built interactive dashboards in IBM Cognos Analytics to visualize current and future technology trends.

# Overview
This project analyzes technology survey data to identify current and future trends in programming languages, databases, platforms, and web frameworks.

The project was completed as part of the IBM Data Analyst Professional Certificate.

## Tools Used:
- Python
- Pandas
- IBM Cognos Analytics
- CSV

## Data Analysis:
Python and Pandas were used to process and analyze the survey data.

# The analysis included:
- Splitting multi-value survey responses
- Expanding values into individual rows
- Counting technology usage
- Identifying the top 10 technologies in each category
- Exporting processed results to CSV files

## Dashboard:
IBM Cognos Analytics was used to create a three-page dashboard covering:

1) Current Technology Usage
2) Future Technology Trends
3) Respondent Demographics

## Project Files:
- Python scripts for data processing and analysis
- Processed CSV datasets
- IBM Cognos Analytics Dashboard
- Final Project Presentation
